# Ilustrações do Figma

Origem: arquivo `CxUW0dj8NZVSxh68jL60yJ`, fornecido para implementação.

- `mascot-home.svg`: início, `11:13`, asset `16cb0.svg`.
- `mascot-pink.svg`: preparação, `11:31`, asset `30e7c.svg`.
- `mascot-gold.svg`: conclusão, `11:73`, asset `f055b.svg`.
- `person.svg`: ajuste da câmera, `2067:8`, asset `7da7d.svg`.

Os PNGs são rasterizações transparentes dos SVGs originais em escala 3×, sem
redesenho. Os componentes usam `resizeMode="contain"` e proporções do protótipo:
mascotes 104 × 96; figura 230,4 × 278,4.

## Referência adicional do PDF

`mascot-rest.png` foi renderizado diretamente da região da ilustração na nona
composição de `Group 1.pdf`, sem redesenhar o mascote. A fonte Atkinson Hyperlegible
(Regular/Bold) veio do repositório oficial Google Fonts, diretório
`ofl/atkinsonhyperlegible`, com a licença `fonts/OFL.txt`. As cópias Android ficam em
`android/app/src/main/assets/fonts`; o projeto iOS referencia os arquivos de origem.
