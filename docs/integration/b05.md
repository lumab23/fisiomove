# B05 — integração concluída

O router app.modules.workouts.router está registrado na aplicação real sob
/api/v1. A persistência usa a migração 20261020_0004. Autenticação e vínculo são
os serviços reais B02/B03. Mutações usam SELECT FOR UPDATE no PostgreSQL;
duas edições concorrentes foram testadas e produziram revisões 3 e 4.

Criação/edição gera revisão nova. Publicar copia o rascunho em revisão publicada;
edição posterior retorna o agregado a draft até republicação. Arquivar preserva
revisões e é idempotente. PATCH ausente preserva instruções; null limpa instruções;
itens substituem a lista inteira. Snapshots não consultam o catálogo atualizado.

WorkoutService.published_snapshot(user, workout_id, revision_id) fornece a B07
uma cópia autorizada de revisão publicada, inclusive após arquivamento. B07
continua responsável pela elegibilidade e persistência de sessões.

Ver sequência manual em ../modules/workouts.md.
